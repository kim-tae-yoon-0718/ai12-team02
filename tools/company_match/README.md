# 회사 참여 후보 추천

회사 정보를 한 번 저장한 뒤 공식 추출표 v5와 대조하여 공고를 세 묶음으로 보여줍니다.

- **우선 검토 후보**: 코드로 완전히 비교 가능한 조건이 하나 이상 일치하고
  명시적 충돌이 없음. 다른 조건의 `사람 확인 필요` 표시는 그대로 유지됨
- **확인 필요**: 명시적 충돌은 없지만 사람이 읽어야 하는 자유 서술 조건이 남음
- **제외**: 닫힌 구조 값에서 명시적인 불일치가 확인됨

`우선 검토 후보`도 참가 가능 확정이라는 뜻은 아닙니다. 이 결과는 검토 순서를
돕는 자료이며 법적인 입찰 참가 자격 확정 결과가 아닙니다.
자격·업종·공동수급 문구는 비슷한 단어만으로 충족 처리하지 않고, 원문과 위치를
함께 표시합니다. 현재 3단계 모델·평가 실행 경로는 수정하지 않습니다.

## 실행

```bash
RAG_ROOT=/srv/rfp python3 tools/company_match/session_start.py
```

기본값은 회사 추천 기능을 먼저 보여주는 상태입니다. 기존 3단계 질의응답으로 바로
들어가려면 `config/base.yaml`의 다음 한 줄만 바꿉니다.

```yaml
company_recommendation_enabled: false
```

회사 프로필은 `data/company_profiles/company_profiles.csv`에 저장되며 Git에는
포함되지 않습니다.
